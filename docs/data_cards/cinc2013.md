# Data card — PhysioNet/Computing in Cardiology Challenge 2013, set A

**What it is.** One-minute abdominal recordings with reference fetal beat annotations.
Source: PhysioNet, *Noninvasive Fetal ECG: The PhysioNet/Computing in Cardiology Challenge 2013*, training set A.

**Licence.** Not re-read in this rebuild. Check the dataset page before redistribution; the data are not committed to this repository.

**Role in this project.** Ground truth for fetal beat detection.

| Item | Value | Where it was checked |
|---|---|---|
| Recordings | 75 (`a01`–`a75`) | files |
| Channels | 4 abdominal, 1000 Hz, 60 s | record headers |
| Reference | fetal QRS positions (`.fqrs`) | files |

**Split.** `splits/cinc2013.json`: development `a01`–`a25` (settings were tuned here), test `a26`–`a75` (run once per pipeline version).

**Things to know**

- The reference of `a54` holds only 37 beats (verified in the file). It is kept in the test set and listed.
- Seven references (`a33`, `a38`, `a47`, `a52`, `a54`, `a71`, `a74`) are reported as doubtful in the literature. This list came from a literature search and was **not** read in the original paper; results are given with and without these recordings.
- No maternal chest lead: the mother's beats have to be found in the abdominal channels.
- Later gestation and stronger fetal ECG than NInFEA. A pipeline that works here does not automatically work at 21–27 weeks (see run `wp3_trust_check`).
