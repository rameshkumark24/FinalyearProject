Final re-run check
==================
Every analysis was run again from the start with scripts/run_all.py on the final code (analysis
package hash fe14c714b7e8, git commit 71d81f9) on 28 Oct 2026, from 01:53 to 10:23 local time: all
37 steps (wp1 to wp18, the Heartbeat and CARDIUM index files, and the export of the one-patient
tool's artifacts), each ending with exit code 0. The steps took 8.5 hours in all; one of them
(wp5_structure_heartbeat_2T: 282.7 minutes, against 31.2 on 27 Oct) ran while the laptop slept, so
about 4.3 hours were computing if that step is counted at its 27 Oct length.

Run wp15_reference_models was not re-run here: it executes the Heartbeat authors' downloaded code,
which the assistant's safety check does not run. The team leader ran it on 28 Oct on the same code
(commit 34c6cbf); neither its script nor the analysis package has changed since.

Before the re-run, every run folder (private per-patient files included) and the six private index
files were copied aside. scripts/compare_runs.py then compared the new outputs with that copy
(provenance.json, which holds run times and the git commit, is not compared).

Result: every per-case output and every metric is identical, and so are the six private index
files. The only differences are
- the run times of the four echo structure runs ("minutes" in metrics.json);
- the creation date on the one-patient tool's three artifact cards (17 Oct before, 28 Oct now),
  which changes the card hashes listed in runs/tool_artifacts/metrics.json; every array file of the
  artifacts is byte-identical;
- run wp16_structure_transfer now also lists the authors' six released models in its
  trimester-shift comparison, because run wp15 exists; all of its earlier values are unchanged.
The two runs kept from the first held-out passes (wp1_cinc2013_v1_first_run and
wp3_trust_check_v1_prespecified) are records of those passes and are not re-run.

The regenerated report differs only in the run times shown in the gates table and in the authors'
models added to the trimester-shift table (section 13.5). Tests: 118 of 118 pass. Audit: 5 of 5
checks pass.
